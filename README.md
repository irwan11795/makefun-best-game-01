**Emberwatch** — defend the Last Lighthouse from ten waves of shadow wisps. A complete tower-defense game: four towers with real trade-offs (Brazier, Lantern, Prism, Ember Mortar), upgrades, selling, five enemy kinds plus a boss, a win screen and a lose screen, a HUD, synthesized sound, and a start/restart loop. Keyboard and mouse. No network, no build step — plain static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. Click a glowing plot, pick a tower (keys 1-4), press Space to send the next wave. Survive all 10 waves to win.
